# maziar0z.github.io

Personal website of Maziar Zamanpour, live at https://maziar0z.github.io

## What's in here

| File | What it is |
|---|---|
| `index.html` | Home page (hero, "How I work", links to the other pages, skills) |
| `research.html` | Ph.D. research, awards, talks, publications, education |
| `industry.html` | Bio-Techne internship (on-time delivery analytics) |
| `ventures.html` | NSF I-Corps / MobiliSlice |
| `style.css` | All colors, fonts and layout. Change `--accent` at the top to re-color the site |
| `images/` | Photos used on the pages |
| `resume.pdf` | Your resume (the "Download resume" buttons link here) |

## How to edit (no software needed)

1. Open the file on GitHub and click the pencil icon.
2. Change the text between the tags. For example, in `<p>some text</p>` only edit "some text".
3. Click **Commit changes**. The live site updates in 1–2 minutes.

To replace a photo or your resume, go to **Add file → Upload files** and upload a file with the **same name**. It overwrites the old one.
